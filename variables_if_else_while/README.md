Exercises on variables and conditions:

positive_or_negative: check if a number is positive or negative

last_digit: print the last digit of a number

print_alphabet: print the alphabet

print_alphabets: replace A by e and a by i

print_alphabt: print the alphabet without q and e

print_numbers: print numbers from 0 to 9

print_numberz: print numbers from 0 to 9 using putchar

print_tebahpla: print the alphabet backwards

print_base16: print numbers from 0 to 9 and letters from a to f

print_comb: print numbers from 0 to 9 with space and dots
